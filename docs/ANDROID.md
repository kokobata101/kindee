# สร้างแอป Android (APK) ของกินดี

แอป Android คือรุ่นเว็บเดียวกันที่ห่อด้วย [Capacitor](https://capacitorjs.com) ข้อมูลยังเก็บในเครื่องเหมือนเดิม ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์

## วิธีที่ 1 — ให้ GitHub สร้างให้ (ไม่ต้องลงอะไรในเครื่อง)

1. อัปโหลดโปรเจกต์ขึ้น GitHub (repository ของคุณเอง)
2. เปิดแท็บ **Actions** > **Build Android APK** > **Run workflow**
3. รอประมาณ 5–10 นาที แล้วดาวน์โหลดไฟล์ `kindee-*.apk` ที่หัวข้อ **Artifacts** ท้ายหน้าผลลัพธ์
4. ส่งไฟล์เข้ามือถือ เปิดติดตั้ง (ต้องอนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก" ครั้งแรก)

ถ้าผลัก tag เช่น `git tag v0.5.0 && git push --tags` ไฟล์ APK จะถูกแนบไว้ในหน้า Releases ให้ทุกคนโหลดได้

## วิธีที่ 2 — สร้างบนเครื่องตัวเอง

ต้องมี Node.js 20+, JDK 21 และ Android Studio (หรือ Android SDK)

```bash
npm ci
npm run android:sync     # build รุ่น portable แล้วคัดลอกเข้าโปรเจกต์ android/
cd android && ./gradlew assembleDebug
# ไฟล์อยู่ที่ android/app/build/outputs/apk/debug/app-debug.apk
```

หรือ `npm run android:open` เพื่อเปิดใน Android Studio แล้วกด Run

## ข้อควรรู้

- ไฟล์ APK จาก workflow เป็นแบบ **debug** (เซ็นด้วยคีย์ดีบัก) ติดตั้งใช้งานได้ แต่ยังลง Google Play ไม่ได้ ถ้าจะขึ้น Play ต้องสร้าง keystore ของตัวเองแล้วทำรุ่น release
- สแกนบาร์โค้ด: แอปจะขออนุญาตกล้องตอนกดสแกนครั้งแรก
- สำรองข้อมูล/ส่งออก CSV: บนแอปจะเปิดหน้าต่างแชร์ของระบบ (เลือก "บันทึกลงไฟล์" หรือส่งเข้าแอปอื่น)
- ปุ่มพิมพ์/บันทึกเป็น PDF ใช้ไม่ได้ใน WebView ของแอป ให้ใช้ CSV หรือรุ่นเว็บแทน
- **สถานะการทดสอบ:** ขั้นตอนห่อ Capacitor และ `cap sync` ทดสอบแล้ว แต่ตัวไฟล์ APK ยังไม่เคยถูกสร้างหรือติดตั้งบนเครื่องจริงโดยผู้พัฒนาเริ่มต้น (สภาพแวดล้อมที่เขียนโค้ดดาวน์โหลด Android toolchain ไม่ได้) หากพบปัญหา โปรดเปิด issue พร้อมข้อความ error
