# แอป iOS (iPhone / iPad) ของกินดี

มีให้ 3 ทาง เรียงจากง่ายไปยาก

## ทางที่ 1 — ติดตั้งจากเว็บ (PWA) ง่ายที่สุด ไม่ต้องมี Mac ไม่ต้องเสียเงิน

1. วางโฟลเดอร์รุ่นเว็บ (`kindee-pwa`) บนโฮสต์ https เช่น GitHub Pages
2. เปิดลิงก์ด้วย **Safari** บน iPhone
3. กดปุ่มแชร์ > **เพิ่มไปยังหน้าจอโฮม**

จะได้ไอคอนบนหน้าจอและเปิดเต็มจอเหมือนแอป ใช้ออฟไลน์ได้ ข้อจำกัดของ iOS: ข้อมูลของเว็บแอปอาจถูกลบถ้าไม่ได้เปิดใช้นานหลายสัปดาห์ จึงควรกด สำรองข้อมูล เป็นประจำ

## ทางที่ 2 — สร้างแอปเนทีฟด้วย Xcode (ต้องมี Mac)

ต้องมี macOS, Xcode 16+, Node.js 22+

```bash
npm ci
npm run ios:open        # build รุ่น portable, คัดลอกเข้าโปรเจกต์ ios/ แล้วเปิด Xcode
```

ใน Xcode: เลือกโปรเจกต์ App > Signing & Capabilities > เลือก Team (ใช้ Apple ID ฟรีได้) แล้วกด Run โดยเสียบ iPhone
- Apple ID ฟรี: แอปอยู่ได้ 7 วันแล้วต้องติดตั้งใหม่
- ขึ้น App Store / TestFlight: ต้องสมัคร Apple Developer Program (ราว 99 ดอลลาร์ต่อปี)

## ทางที่ 3 — workflow บน GitHub (รุ่นทดสอบสำหรับ Simulator)

Actions > **Build iOS (simulator)** > Run workflow จะได้ `kindee-ios-simulator.zip` ที่เปิดใน iOS Simulator บน Mac ได้ ใช้ตรวจว่าโปรเจกต์คอมไพล์ผ่าน **ติดตั้งบน iPhone จริงไม่ได้** เพราะ iOS บังคับให้เซ็นชื่อ

## ข้อควรรู้
- สแกนบาร์โค้ด: จะขออนุญาตกล้องตอนกดสแกนครั้งแรก
- สำรองข้อมูล/CSV: เปิดหน้าต่างแชร์ของ iOS (บันทึกลงไฟล์ได้)
- ปุ่มพิมพ์เป็น PDF อาจใช้ไม่ได้ในแอป ให้ใช้ CSV แทน
- **สถานะการทดสอบ:** ผู้พัฒนาเริ่มต้นไม่มี Mac จึงยังไม่เคยคอมไพล์หรือรันโปรเจกต์ iOS นี้ ที่ทดสอบแล้วคือการสร้างโปรเจกต์และ sync ไฟล์เท่านั้น หากพบปัญหาโปรดเปิด issue
